Capítulo III: los 35 camellos

Descripción del capítulo

Cerca de un albergue de caravanas, Beremiz y su compañero encuentran a tres hermanos discutiendo por la herencia de su padre: 35 camellos que deben repartirse así: la mitad para el mayor, un tercio para Hamed y un noveno para Harim, el menor. Como 35 no se divide exactamente entre 2, 3 y 9, ningún reparto los satisfacía. Beremiz suma el camello de su amigo a la herencia (36), entrega 18, 12 y 4 (34 en total) y quedan 2 camellos: uno se devuelve a su dueño y el otro es la recompensa de Beremiz.
En esta versión el problema es general: puedes usar cualquier cantidad de camellos y de herederos, y siempre se reparten camellos enteros.

Algoritmo

  1. Leer el número de camellos n y el denominador d de cada heredero (recibe 1/d).
  2. Calcular el mínimo común múltiplo L de todos los denominadores.
  3. Hallar el menor total T, múltiplo de L, tal que T ≥ n. Se prestan k = T − n camellos.
  4. Cada heredero recibe T / d, que siempre es un entero.
  5. Sobrantes = T − (suma de partes). Se devuelven los k prestados y lo que queda es la ganancia.
  6. Si los sobrantes no alcanzan para devolver los k prestados, ese reparto no es posible.

Capítulo IV: los ocho panes

Descripción del capítulo

Camino a Bagdad encuentran al jeque Salem Nassair, malherido y hambriento. El bagdalí lleva 3 panes y Beremiz lleva 5. Juntan los 8 panes y los comen entre los tres. Al llegar, el jeque paga 8 monedas de oro. La división simple sería 5 monedas y 3 monedas, pero Beremiz demuestra que la división cierta es 7 y 1: cortando cada pan en 3 pedazos hubo 24 pedazos, cada uno comió 8, así que Beremiz dio 7 y su compañero dio 1. Después propone la división perfecta: 4 monedas para cada uno.

Algoritmo

  1. Leer los panes del primero (a), los del segundo (b) y las monedas pagadas (M).
  2. Cortar cada pan en 3 pedazos. Total de pedazos = 3(a + b). Como comen 3 personas, cada una come T = a + b pedazos.
  3. Pedazos que dio cada uno al jeque: 3a − T y 3b − T (nunca negativos).
  4. División simple: proporcional a los panes. División cierta: M · (pedazos dados) / T. División perfecta: M / 2 para cada uno.

Ejercicio 12: raíces de una ecuación cuadrática

Descripción del ejercicio

Programa que determina las raíces reales de ax² + bx + c = 0. El usuario ingresa las constantes a, b y c, y el programa calcula el discriminante D = b² − 4ac. Si D > 0 muestra "The equation has two roots" y las dos raíces; si D = 0 muestra "The equation has one root" y la raíz; si D < 0 muestra "The equation has no real roots". Se prueba con (a) 3x² + 6x + 3 = 0, (b) −3x² + 4x − 6 = 0 y (c) −3x² + 7x + 5 = 0.

Algoritmo

  1. Leer a, b, c (a debe ser distinto de 0).
  2. Calcular D = b² − 4ac.
  3. Si D > 0: dos raíces, x = (−b ± √D) / 2a.
  4. Si D = 0: una raíz, x = −b / 2a.
  5. Si D < 0: no hay raíces reales.

Ejercicio 13: estimación de π

Descripción del ejercicio

El valor de π se puede estimar con la expresión √(6 · Σ 1/n²), sumando desde n = 1 hasta un valor N. Se calcula con un ciclo y se compara con el valor real de π (equivalente a format long en MATLAB, es decir, 15 decimales). El ejercicio pide probar con N = 100, N = 10000 y N = 1000000. En esta versión N llega hasta 1.000.000.

Algoritmo

  1. Leer N (entero entre 1 y 1.000.000).
  2. suma = 0. Para n desde 1 hasta N: suma = suma + 1/n².
  3. estimación = √(6 · suma).
  4. Comparar con Math.PI y calcular el error absoluto.
